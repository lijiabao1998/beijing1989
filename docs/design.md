# 設計文件 — 《北京，一九八九》（An Ordinary Spring）

## 一、核心命題與敘事邊界
- **核心體驗**：不是「改寫歷史」，而是讓玩家透過四名背景截然不同的北京普通人，在同一段確定的七週春光裡，體驗有限資訊下的判斷、記憶偏差、鄰里互助與各自留下的物證。
- **嚴格禁區**：
  - 無戰鬥、無武器、無計分或勝負評估（`tests/validate-data.mjs` 與 `tests/smoke.mjs` 以正則禁止任何計分或擊殺詞彙）。
  - 真實歷史人物不編寫台詞或虛擬動作，僅以具出處的引文出現；所有可對話角色在資料中強制標記 `fictional: true`。
  - 六月三日至四日之夜以胡同守望、廣播見聞與清晨餘韻處理，不製作成任何動作關卡。

---

## 二、四線三十二章與時間軸架構
遊戲包含 **4 條完整可遊玩視角線 × 8 個歷史日期 ＝ 32 章**，每章包含獨立的場景串接、時間推進 (`clockMin`)、拍照目標與個人結局去向：

1. **日期序列**：`1989-04-17`、`04-22`、`04-27`、`05-04`、`05-13`、`05-20`、`05-30`、`06-03`（延伸至 6/05 清晨尾聲）。
2. **四條視角線**：
   - **學生（`student`｜`ch0`–`ch5` + `ch-0427`, `ch-0504`）**：陳立
   - **工人（`worker`｜`w0`–`w5` + `w-0427`, `w-0504`）**：王建國
   - **記者（`journalist`｜`j-0417`–`j-0603`）**：顧明遠
   - **市民（`resident`｜`r-0417`–`r-0603`）**：沈淑芬
3. **世界線賬本（`WorldTimelineLedger`）**：
   - `xr:*` 跨線因果旗標（定義於 `data/worldFlags.json`）在某一視角觸發後，會寫入共用的跨線賬本。
   - 其他視角的對話節點透過 `variants`（支援 `world:xr:...`、`rel:...`、`time:...` 條件）呈現因果迴響；讀取舊快照若偵測到世界線已更新，會提示玩家「同步最新世界線」或「沿用原快照」。

## 三、探索、對話與紀實機制
- **物理探索與碰撞**：玩家具備步行、攝影步行、二八自行車、平板貨運三輪車四種骨架與移動模式；所有場景依地形與建築物件定義 `WorldCollider`（盒狀與圓形碰撞體）與 `AABB6` 遮擋體，確保建築、機床、桌椅與路障具備實體阻隔，同時保留自動引導探索不卡點。
- **有限資訊與羅生門證據比對**：
  - 傳言（`kind: "fiction"`, `confidence: "uncertain"`）可選擇輕信、轉述或實地求證。
  - 玩家可從現場對話、告示與新聞清樣蒐集 `official_print / rumor / witness / photo / audio_tape` 五類證物卡，並於筆記本內配對核對，系統以中性詞彙標示：「兩份紀錄吻合（corroborated）」「說法存在出入（contradiction）」「尚無旁證（unverified）」。
- **攝影取景與暗房顯影**：按 `F` 切換 35mm 單眼取景框（`35mm / 50mm / 85mm` 焦段），透過視椎體與 `occluders` 遮擋判定鎖定歷史目標；拍攝結果即時生成銀鹽底片存於暗房供沖印與納入紀念冊。
- **時代互動器物特寫**：內建 3D 互動檢視的「三角地布告欄」「夜班鉛字排版桌」「牡丹牌短波收音機」（需手動調頻鎖定電台訊號）。
- **分支圖與紀念保存**：章末分支圖標記已走過／未選／未觸及分支；「六十四開連環畫冊」支援單篇八章與四線三十二章合訂翻閱，並可匯出離線 HTML 可列印紀念冊；「紀實長片」支援單章、本篇全八章及「四線交織編年長片（32 章／四線同框）」。

## 四、3D 場景管線與效能預算
- **24 個程式化 3D 場景**：全數定義於 `data/scenes.json`（含 `spawn`、`bounds`、`cam`、`atmosphere`、`defaultCue`、`stepSurface`），涵蓋北大校園、海淀街區、4/22 與 4/27 遊行隊伍、長安街、天安門廣場、絕食營地、民主女神像、木樨地路障、北京飯店陽台、《首都晨報》編輯部與暗房、過街天橋、新華門、醫院急診外、西單四合院與大雜院、第二機床廠、清晨菜場、胡同與震後晨景。
- **高密度零穿模群眾系統（`marchProcession.ts`）**：多列遊行學生、手挽手糾察線、旗手與持大型漢字標語牌隊伍採用局部幾何避障投影與非對稱推離求解，確保行進人物與沿街住戶、路燈、站牌與玩家保持安全距離不穿模。
- **服裝局部染色與雙面旗幟**：所有群眾模型以自訂頂點屬性 `aTint`（`tintLitMat`）僅替換夾克與袖子色調，保留自然膚色、黑髮與白色頭巾；懸掛雙面標語使用背靠背雙平面（`makeTwoSidedPlaneGeo`），正反兩面文字皆正向不鏡像。
- **嚴格資源生命週期與手機效能預算**：
  - `WorldManager` LRU 快取上限 3 個世界實例，場景卸載時精準回收非共用幾何、材質與 `sceneOwned` 畫布貼圖。
  - `tests/smoke.mjs` 在桌面（`1366×800`）與手機（`390×844`）上連續 3 輪巡迴檢查全部 24 景：強制要求每景 **繪製呼叫 ≤ 60 draw calls**、**場景三角形 ≤ 300,000 tris**、**第 2 輪與第 3 輪結束時 GPU 幾何與貼圖數完全一致（零洩漏）**，且零 console/page 錯誤。
