# 設計文件

## 核心
不是「玩家如何改變歷史」，而是：在結果已經確定的歷史中，一個普通人看到了什麼、相信了什麼、幫助了誰、留下了什麼。

## 機制
- **有限資訊下的選擇**：傳言（event `kind: fiction`, `confidence: uncertain`）可以 相信／轉述／親自確認。
- **狀態**：旗標、物品（信、暖壺）、人際關係（數值只影響對話，不顯示分數）、日記。
- **結局**：章節結局是個人的去向，不是勝負。歷史節點不可改寫。
- **禁止**：戰鬥、死亡分數、「正確」選項、為真實人物編台詞。`tests/validate-data.mjs` 會檢查角色都標 `fictional: true`，事件都有來源與確認程度。

## 視角（後期）
學生（可玩）、工人、記者、市民。同一事件，四人各知一部分；玩完四條線才拼出較完整的面貌。
