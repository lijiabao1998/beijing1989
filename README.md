# 北京，一九八九 — An Ordinary Spring

線上試玩：<https://game.lijiabao.uk/beijing1989/>

**前提**：歷史的結果已經確定。你扮演一位普通北京人——看到了什麼、相信了什麼、幫助了誰，以及最後留下了什麼。

這是一款結合 **3D 城市探索、四線多視角歷史敘事、證據交叉比對、35mm 膠片攝影與時代器物互動** 的紀實互動作品，不是生存遊戲，也不是射擊遊戲。

---

## 核心內容規模（四條視角線 × 八章 ＝ 三十二章）

跨越 **1989 年 4 月 17 日 至 6 月 5 日** 八個關鍵歷史日期，四名虛構主角在 **24 個即時程式化 3D 北京場景** 中走過各自相連的春天：

| 視角篇 | 虛構主角 | 起點與代表空間 | 核心體驗特色 |
|---|---|---|---|
| **第一篇・學生視角** | 陳立（北大物理系學生） | 北大三角地、海淀街道、4/22 與 4/27 高密度遊行隊伍、廣場絕食營地、民主女神像前、深夜胡同 | 學生動員、夜間行進糾察與無穿模群眾、廣場留守見聞 |
| **第二篇・工人視角** | 王建國（第二機床廠車工） | 鋸齒天窗機床廠（C6140 車床・行車）、工人民宅大雜院、平板三輪車、路口路障 | 夜班車間停水停電抉擇、工會與市民聲援、三輪車護送物資 |
| **第三篇・記者視角** | 顧明遠（《首都晨報》記者） | 《首都晨報》夜班編輯部與紅燈暗房、北京飯店陽台長焦機位、木樨地過街天橋、新華門前 | 35mm SLR 相機實時取景、暗房銀鹽洗印、新聞清樣發排與證據比對 |
| **第四篇・市民視角** | 沈淑芬（西單四合院退休護師） | 漢磚灰瓦四合院北房、北京急救站門口、清晨菜場糧油排隊點、雨夜長安街 | 牡丹牌短波收音機手動調頻、鄰里急救物資包紮、街坊見聞筆記 |

### 八個相連的歷史日期（1989）
1. **4/17 夜**：悼念集會初起與西校門夜色
2. **4/21–4/22**：十里深夜進發與天安門廣場追悼晨景
3. **4/27 日間**：大規模市民與學生遊行（多列縱隊・校旗與手工標語・糾察線・沿街送水市民）
4. **5/04**：五四七十週年遊行與新聞界訴求
5. **5/13–5/15**：廣場絕食帳篷營地、紅十字救護車與醫院急診通道
6. **5/19–5/20**：無軌電車路口路障、公用電話亭與四合院短波夜聽
7. **5/30–5/31**：黃昏民主女神像腳手架與陰雨長安街
8. **6/03–6/05（尾聲）**：深夜胡同、晨霧洗淨的布告欄、編輯部與清晨菜場，匯聚「五、四線對照・真相拼圖」總結

## 主要玩法與功能

- 開場的電影序幕共 34 秒。可以用空白鍵暫停、Esc 略過，也能在選角頁或遊戲選單重播。
- **操作方式**：`WASD`／方向鍵／左下虛擬搖桿移動；滑鼠右鍵拖曳或視角按鈕旋轉視角，滾輪縮放；`E`／空白鍵互動；`F` 進入 35mm 取景框（`1/2/3` 或 `V` 切換 `35mm / 50mm / 85mm` 焦段）；`G` 切換三種影像風格（寫實膠片 / 黑白紀實 / 彩墨連環）；`M` 開啟地圖與四線時間軸。
- **標題畫面即時預覽**：於首頁切換四條視角卡片，3D 背景即同步切換為對應主角與代表場景。
- **跨線世界線賬本（`WorldTimelineLedger`）**：`xr:*` 跨線旗標讓一條路線的行動真實影響同日及後續其他視角的對話與世界狀態；重玩歷史快照時若遇世界線變動，可選擇同步最新世界線或保留原快照。
- **證據對照與羅生門檔案**：收集 `official_print / rumor / witness / photo / audio_tape` 五類證物，在筆記本中成對比對，以中性標記顯示「兩份紀錄吻合／說法存在出入／尚無旁證」。
- **35mm 暗房、時代器物特寫與短波收音機**：於場景中拍攝的底片可進入紅燈暗房顯影與揀選印樣；可隨時檢視「三角地布告欄」「夜班鉛字排版桌」「牡丹牌短波收音機」3D 互動器物特寫。
- **六十四開連環畫冊＆四線交織紀錄長片**：支援單篇八章或「四線合訂本」逐頁翻閱並匯出離線可列印 HTML／PDF 個人紀念冊；亦支援單篇與 32 章「四線交織編年長片」播放（`1x–10x` 倍速、四線同框對照、`32` 段紀實旁白與 `22` 首配樂音效）。

## 設計與史料倫理原則
- **歷史固定，個人命運與見聞分岔。** 不改寫歷史結果；抉擇影響人際聚散、隨身物件、日記、底片與跨線印記。
- **沒有戰鬥、沒有計分概念，也沒有所謂「唯一標準選項」。**
- **真實人物不編寫對話**：所有發言角色皆於資料與 `tests/validate-data.mjs` 中強制驗證為 `fictional: true`。
- **史料可查核**：`data/events/1989-*.json` 內建 36 筆公開歷史／證言／傳聞條目，附 `sources[]` 與 `confidence`（`documented / testimony / uncertain`），遊戲中可隨時開啟「史料」查閱；參考影像規範見 [docs/references.md](docs/references.md)。

## 專案結構

| 路徑 | 說明 |
|---|---|
| `src/render/` | Three.js 程式化建築地標（北大西門、天安門軸線、機床廠、大雜院、北京飯店陽台、夜班編輯部、木樨地天橋、新華門、醫院大門、菜場等 24 景）、`WorldManager` LRU 資源回收、無穿模高密度遊行系統、選擇性服裝染色材質與後製膠片管線 |
| `src/play/` | 角色骨架動畫（步行 / 二八自行車 / 三輪車 / 持機記者）、滑鼠與觸控控制、WebAudio 程式化環境音與 `22` 條音軌（`audio.ts`）、分視角旁白朗讀 |
| `src/save/` | 本機多視角進度存檔、章節快照與 `WorldTimelineLedger` 跨線因果賬本 |
| `src/ui/` | 六十四開連環畫冊與紀念冊匯出、四線紀錄長片播放器（`documentaryReel.ts`）、3D 時代器物特寫（`tactileObjects.ts`）、暗房沖印、證據交叉對照、分支圖與史料檢視 |
| `data/events/` | 36 筆公開史料事件 JSON 與四線 32 章節表 |
| `data/dialogue/` | 資料驅動的 32 份對話腳本（4 視角 × 8 章） |
| `public/assets/` & `public/audio/` | 32 幅連環畫插畫（`≤ 250 KiB`）、22 首配樂音效與 32 段旁白音訊 |
| `tests/` | `validate-data.mjs` 資料／資產完整度檢查、`smoke.mjs` 雙裝置（桌面＋手機）全場景與全路線無頭瀏覽器回歸測試 |

## 開發與驗證命令

```bash
npm ci
npm run dev        # 啟動 Vite 本機開發伺服器
npm run validate   # 驗證 36 事件、32 章節、24 場景、22 音效、32 插畫與倫理規則
npm run build      # TypeScript 型別檢查 + Vite 靜態建置
npm run smoke      # Puppeteer 全 24 景三輪資源防洩漏審計 + 四線通關驗證（需 Chrome/Edge）
```
