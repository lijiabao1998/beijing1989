# 北京，一九八九 — An Ordinary Spring

線上試玩：<https://game.lijiabao.uk/beijing1989/>

**前提**：歷史的結果已經確定。你扮演一個普通人——看到了什麼、相信了什麼、幫助了誰，以及最後留下了什麼。

這是一款「歷史敘事＋城市探索＋人物命運模擬」遊戲，不是生存遊戲，也不是射擊遊戲。

## 目前可玩：全六章線性紀事（1989 年 4 月 17 日 – 6 月 5 日）
一名虛構的北京大學學生，在六個相連的春天日子裡走過十個 3D 低多邊形場景（支持跨章狀態延續與一鍵線性引導）：
1. **第一章　四月十七日，夜**：北大校園（宿舍、大字報布告欄、老周、林小梅、西校門）→ 騎二八自行車進城（海淀街道）→ 長安街・天安門。
2. **第二章　四月二十一日夜至二十二日**：北大校園 → 深夜行進隊伍（糾察線、沿街住戶）→ 清晨天安門廣場（追悼會轉播、人民大會堂台階）。
3. **第三章　五月十三日至十五日**：北大校園 → 海淀街道（報刊亭、王師傅綠豆湯三輪車、救護車志願者）→ 天安門廣場絕食營地（帆布帳篷、廣播站、急救通道）。
4. **第四章　五月十九日夜至二十日**：北大校園 → 戒嚴夜路口（雙節無軌電車路障、公用電話亭）→ 清晨長安街。
5. **第五章　五月三十日**：暮色廣場（白色石膏雕像與腳手架、舊帳篷區）→ 傍晚海淀街道 → 深夜北大校園。
6. **第六章　六月三日夜至四日（尾聲）**：深夜胡同口與收音機 → 六月五日清晨空寂的北大校園（洗淨的布告欄、宿舍書桌與「完整春日紀事」全六章總結）。

操作：WASD／方向鍵或左下搖桿移動，E／空白鍵或右下按鈕互動，滾輪或雙指縮放；上方 HUD 提供章節時間軸、線性探索引導（「引導前往」）、即時環境音開關與「播放本章紀錄短片」。

## 設計原則
- **歷史固定，個人故事分岔。** 不改寫歷史結果；選擇只改變人際關係、隨身物品和日記。
- **有限資訊下的選擇。** 傳言只能相信、轉述，或自己去確認。
- **沒有戰鬥、沒有死亡分數、沒有「歷史正確選項」。**
- **真實人物不編台詞。** 不替任何真實人物（包括遇難者）編寫對話或行動；真實人物只會以有出處的引文出現。所有角色皆為虛構。
- **史料可查。** 每個事件標示「史實／證言／虛構」和確認程度（documented / testimony / uncertain），遊戲中可打開「史料」查看來源。

## 史料政策
- 事件資料在 `data/events/*.json`，每筆有日期、地點、`sources[]`、`confidence`。
- 史實事件至少一個可公開查閱的來源；只有一個證言來源的標 `testimony`；無法確認的標 `uncertain`。
- 參考圖片只用自由授權素材，記錄在 [docs/references.md](docs/references.md)。現代 OSM 不是 1989 年的北京，不直接匯入。

## 結構
| 路徑 | 內容 |
|---|---|
| `src/render` | Three.js 3D 場景、地標與道具（校園、街道、行進、長安街、廣場、營地、路障、雕像、胡同、清晨校園） |
| `src/play` | 移動、操作、對話執行器、WebAudio 程式化環境音與音效（`audio.ts`） |
| `src/save` | 本機存檔（章節、旗標、物品、關係、日記、章節快照） |
| `src/ui` | 史料檢視、Detroit 式分支圖、木刻過場插畫與紀錄短片播放器（`cinematic.ts`） |
| `data/events` | 歷史事件與章節表 |
| `data/dialogue` | 資料驅動的雙視角全十二章對話樹（學生 `ch0`–`ch5` 與工人 `w0`–`w5`） |
| `public/assets` | 十二章木刻風格插畫橫幅（`ch0`–`ch5.jpg`、`w0`–`w5.jpg`） |
| `tools/` | 離線地圖管線（佔位） |
| `docs/` | [design](docs/design.md)、[timeline](docs/timeline.md)、[references](docs/references.md) |

```
npm ci
npm run dev        # 本機

npm run validate   # 資料檢查
npm run smoke      # Puppeteer 冒煙測試（需 Chrome/Edge，CHROME_PATH 可指定）
```

## 地標與場景

- 五月營地與路障：廣場帳篷、廣播站喇叭、紅十字救護車與綠豆湯三輪車、無軌電車路口路障、公用電話亭、白色石膏雕像與腳手架、深夜胡同與收音機
